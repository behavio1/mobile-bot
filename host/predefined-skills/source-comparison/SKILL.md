# Source Comparison

State the options and comparison criteria before judging them. Use the same criteria for every option and separate required criteria from preferences. Base each comparison row or statement on inspected evidence, citing the source that supports it.

Normalize units, dates, versions, scope, and commercial terms before comparing values. Mark missing or incomparable information as unknown; do not turn absence of evidence into a negative result. When sources disagree, show the disagreement and identify whether freshness, authority, or scope explains it.

Conclude with the option that best fits the stated criteria, the trade-offs that matter, and any decision that still needs the owner's input.
