# Task Planning

Start from the requested outcome, deadline, constraints, and known dependencies. Ask only for information that changes the plan materially. Break the goal into the smallest useful sequence of actions and put prerequisites before dependent work.

Each step must name its output or completion signal. Keep decisions that require the owner visible, and distinguish them from actions the agent can perform. Avoid adding tools, ceremonies, or future scope that the goal does not require.

Update the plan from observed progress. Mark work complete only after its completion signal is verified, and carry unresolved blockers into the next step or workspace checkpoint.
