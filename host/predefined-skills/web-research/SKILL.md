# Web Research

Define the question and the evidence needed before searching. Prefer primary sources for factual claims and current official sources for information that can change. Record the source URL, publication or update date when visible, and the exact fact each source supports.

Search in focused passes. Open the strongest candidate sources, inspect their contents, and distinguish source facts from your own conclusions. If sources conflict, report the conflict and explain which evidence is stronger instead of silently choosing one.

Finish with a direct answer, a short evidence trail, and any unresolved gaps. Do not claim that a source supports a fact unless you read the relevant content. Save durable findings in the agent workspace only when they will help later work, with links back to the original sources.
