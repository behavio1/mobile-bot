# Prompt przewodnika motywu

Dostosuj ten szablon do tematu klienta i zapisz pełną, konkretną treść w guide-prompt.md:

Create a single full-body welcoming guide for the Mobile Bot [THEME NAME] theme. Match the visual identity of avatar index 1 from the selected artwork set: [FACE / SPECIES / HAIR / CLOTHING]. Seated in a relaxed pose on [ONE SMALL THEMED SEAT], feet visible, holding a small phone in one hand and waving hello with the other. Friendly, capable, calm adult tone. Polished hand-drawn comic contours and restrained cel shading, [THEME PALETTE]. Compact silhouette readable at 150 dp, entire subject inside the frame with 12% breathing room. True transparent PNG alpha background. No floor, glow, background card, text, speech bubble, logos, numbers or UI controls. The UI adds its own changing speech bubble. Preserve existing agent identity and roster; this is a visual counterpart, not a new agent role.

W promptcie podaj konkretne cechy zamiast nawiasów. Przy temacie Kosmiczna załoga możesz opisać przyjaznego przewodnika w granatowo-turkusowym kombinezonie, bez hełmu zasłaniającego twarz, na małej skrzyni orbitalnej. Nie dodawaj znaków konkretnych marek ani franczyz.
